زعترة الرقمية — نسخة متجر منتجات رقمية

هذه نسخة واجهة كاملة قابلة للتعديل والرفع على الاستضافة.
المنتجات موجودة في app.js داخل const products.

مهم:
- الدفع الحالي تجريبي فقط ولا يسحب أي أموال.
- لا تدخل بيانات بطاقة حقيقية في النسخة التجريبية.
- روابط التحميل الحقيقية للملفات لم تتم إضافتها بعد.
- لتحويله إلى متجر فعلي نحتاج استضافة + نظام طلبات/قاعدة بيانات + مزود دفع موثوق + طريقة آمنة لتسليم الملفات الرقمية.

للتعديل:
1) افتح app.js لتغيير أسماء المنتجات والأسعار والوصف.
2) افتح style.css لتغيير الشكل والألوان.
3) افتح index.html لتغيير النصوص والأقسام.

النسخة مناسبة للرفع على خدمات استضافة المواقع الثابتة، وبعدها نقدر نبني لوحة تحكم وإدارة للطلبات والمنتجات.
